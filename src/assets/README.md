# Onboarding reference

`onboarding-reference.webp` reuses the existing Onun feed creation **Onun astronauta em órbita da Terra**, credited in the feed to Onun be AI and generated with Nano Banana.

- Original asset: `public/assets/hero-5.png` in the Onun parent application (3584 × 4608).
- Feed post: `a0010000-0000-4000-8000-000000000005`, seeded by `server/community/seed.ts` from `src/pages/public/data/gallery.ts`.
- This bundled derivative: 900 × 1157 WebP, full image preserved without cropping or creative changes; resized and encoded at quality 84.

Bundling the reference keeps the guided tour independent of the feed API and makes it available in the standalone app.
