The fetched [OpenRouter image-model catalog](https://openrouter.ai/api/v1/images/models) exposed these provider prefixes: `black-forest-labs`, `bytedance-seed`, `google`, `inclusionai`, `krea`, `meta`, `microsoft`, `openai`, `qwen`, `recraft`, `sourceful`, `x-ai`. Only map a provider to its own known authentic asset. A gateway logo may identify OpenRouter as the gateway, but must not be presented as an unknown model developer's logo. Logo retrieval here covers the files above; existing Google, OpenAI, BFL, ByteDance and Runway assets have their earlier source record elsewhere in the project.

Added SVGs contain filled geometry or, for InclusionAI, MiniMax and HeyGen, embedded original transparent PNGs; none contains a script. Qwen and InclusionAI PNG alpha is transparent around the glyphs, so the same monochrome filter keeps the background transparent.

The [live OpenRouter video catalog](https://openrouter.ai/api/v1/videos/models) was checked on 2026-09-26. Its provider prefixes were `alibaba`, `black-forest-labs`, `bytedance`, `google`, `heygen`, `kwaivgi`, `minimax`, `openai`, `runway`, and `x-ai`; all have authentic logo mappings. Examples confirming the additional mappings are `minimax/hailuo-3`, `alibaba/wan-3.0`, `heygen/avatar-iv`, and `kwaivgi/kling-v3.0-pro`.

The MCP icon is the unmodified [official favicon SVG](https://github.com/modelcontextprotocol/docs/blob/573dc60c2e7aab2605b29d0bf27194aa7b02e4fb/favicon.svg), vendored as `public/assets/mcp.svg`. Only a CSS monochrome filter adapts the original black mark to white on the dark interface.
